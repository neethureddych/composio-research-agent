01 · Executive summary

The research covers exactly 100 applications across 10 assignment categories, with 10 apps in each category. A Python research pipeline fetches documentation pages, collects Composio toolkit catalogue records, compares application names, and organizes authentication and credential-access findings.

Key finding: 69 of 100 applications (69.0%) have an exact normalized-name match in the collected Composio catalogue.

An exact-name match is a discovery signal only. It does not prove that all API actions, permissions or workflows are supported.

06 · Research pipeline

Automated steps

  • Read the corrected 100-app assignment CSV.
  • Fetch documentation pages with Python requests and BeautifulSoup.
  • Capture page titles, descriptions, status codes and evidence URLs.
  • Collect toolkit records through the Composio SDK.
  • Compare normalized app names with toolkit names and slugs.
  • Calculate category coverage and authentication distributions.
  • Export consolidated research and review CSV files.

Human verification steps

  • Review whether alternate toolkit names are genuine aliases.
  • Verify authentication and credential setup using official docs.
  • Check REST or GraphQL API availability and API breadth.
  • Review existing MCP support and available actions.
  • Identify gated credentials, permissions and practical blockers.
  • Assess buildability for specific workflows.

07 · Limitations and next steps

  • Exact-name matching can miss integrations listed under alternate names.
  • Potential aliases must be checked before being counted as matches.
  • Documentation fetch success does not prove API functionality.
  • Only five credential-access records have been verified so far.
  • API breadth, REST/GraphQL details, MCP coverage and buildability still require systematic verification.
  • HTTP errors may reflect access restrictions or automated-request handling, not API unavailability.
Research status: This is a partially verified research dataset, not a completed manual audit of all 100 applications. Pending fields are deliberately disclosed rather than presented as confirmed facts.

Next improvements

  • Expand official documentation verification across all categories.
  • Review all 31 exact-name misses for legitimate alternate toolkit names.
  • Inspect toolkit actions and confirm actual integration coverage.
  • Complete API surface, credential accessibility and buildability assessments.
